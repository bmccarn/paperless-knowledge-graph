# Triage labels

These are the configured default role names. Setup records the mapping locally; it does not create or alter GitHub labels.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | More information needed |
| `ready-for-agent` | `ready-for-agent` | Specified enough for autonomous implementation |
| `ready-for-human` | `ready-for-human` | Human implementation needed |
| `wontfix` | `wontfix` | Will not be implemented |

Check existing tracker labels before applying this mapping. Edit the second column if the project adopts different names.
