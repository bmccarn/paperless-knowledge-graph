WF1 · Landing: search first, map second

Superseded by #228: the Graph tab opens a graph at once, and this page is not built. Search, Recent and Most connected live in the graph header.

  1. The page opens on search plus an archive map, never on a force-directed sample. Focus goes to the search box; / returns to it.
  2. The map is a type-level meta-graph: 13 entity types, area = entity count, edge width = √(entity-to-entity links). It never has more than 15 nodes, so it cannot become a hairball. Clicking a type opens the Table view filtered to that type; clicking an edge opens the table of those links.
  3. Documents are a strip of evidence counts by document type, not nodes.
  4. A trust queue lists inferred, unscored and duplicate items, plus recent ingests (from Document.processed_at).
Names are synthetic. All counts are invented.
